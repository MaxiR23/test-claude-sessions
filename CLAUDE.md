# CLAUDE.md

Rules for working in this repository. These are strict. Follow them exactly.

## Branches

- Never commit directly to `main`.
- Branch format: `type/short-description`
  - Lowercase, words separated by hyphens.
  - Examples: `feat/login-page`, `fix/header-bug`, `docs/setup-notes`
- Allowed types: `feat`, `fix`, `docs`, `chore`, `refactor`, `test`, `style`, `perf`, `ci`, `build`
- Do not use any other prefix.

## Commits

- Follow Conventional Commits: `type(optional-scope): short description`
  - Examples: `feat: add login page`, `fix(header): correct alignment`, `docs: add setup notes`
- Same allowed types as branches.
- Write commit messages in English, imperative mood, lowercase description, no trailing period.
- One logical change per commit.

## Shipping

- Branches, commits, pushes, and pull requests are done only through `scripts/ship.sh`.
- Never run raw `git commit`, `git push`, or `gh pr create`.
- Run `scripts/ship.sh prepare <issue> [path ...]` to create the branch and commit.
- After `prepare`, write `.claude/loop/pr-<issue>.body.md` and wait for the owner's approval.
- Only after approval, run `scripts/ship.sh publish <issue>` to push and open or update the pull request.
- After every `publish`, remove the PR footer. This step is required:
  1. Read the PR body with the built-in GitHub tools.
  2. If it ends with a "Generated by Claude Code" footer, remove the footer and its `---` separator using the built-in GitHub tools only. Never use `gh` or `gh api` for this.
  3. Read the PR back with the built-in GitHub tools and confirm the footer is gone. Report the last 3 lines of the body.
  4. Do not change anything else in the body.

## Language

- Code, comments, commits, branches, and pull requests: English.
