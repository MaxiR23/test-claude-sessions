# test-clause-sessions

Practice repository for learning how **Claude Code cloud sessions** work.

## Purpose

This repo is a sandbox. Nothing here is production code. It exists to:

- Test Claude Code sessions running in the cloud (claude.ai/code)
- Verify repository rules are respected (branch naming, conventional commits, no AI attribution)
- Try custom subagents defined in `.claude/agents/`
- Write documentation along the way as study notes

## Rules for this repo

- Branch naming: `type/short-description` (e.g. `feat/login`, `fix/header-bug`, `docs/setup-notes`)
- Commits: Conventional Commits, in English
- No AI attribution in commits, branches, or pull requests

## Status

Experimental. Expect things to be created, broken, and deleted.
